Growing up in the 90s meant growing up side-by-side with the internet and all the technologies that came along with it. I discovered in various IT classes early on that I have a passion for creating interfaces. Over the years I used plain HTML/CSS, WordPress, FTP, Typo3, etc. to host websites for school classes, clubs, and hobbies. Always staying up to date with the latest libraries and frameworks enabled me to create increasingly good solutions.

Since the release of the first smartphones, a brand-new need for user-friendly interfaces emerged. Screens of all sizes and formats needed to be considered. Responsive layouts and cross-platform deployability became more and more relevant. For me that meant focusing on technologies that can deploy interfaces across all common device types, like Flutter, Electron, and React.
