User Experience Design focuses on creating applications that are intuitive, efficient, and enjoyable to use. I connect user needs with technical implementation by turning goals and workflows into clear interfaces, consistent interactions, and predictable system behavior. From a programming perspective, UXD is not only about visuals - it also includes performance, responsiveness, accessibility, error handling, and feedback. 

By designing and building with the user in mind, I help reduce friction, improve usability, and create software that feels reliable and easy to navigate.
