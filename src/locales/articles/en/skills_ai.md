I started my IT career as a self-taught programmer. That means I’ve spent countless hours digging through Stack Overflow, GitHub, and documentation to learn about development and how to put my ideas into practice. My approach has always been, and is to this day, 'learning by doing'. Coding with AI has accelerated this process massively. No longer getting stuck with syntax issues, complex dependency stacks, or unique software patterns allows me to get fast results and see how it is supposed to be done, almost instantly.

My day-to-day programming with familiar technology has changed a lot with AI. Especially on frontend work, this means doing the same patterns many times. Not having to write everything out myself gives me more time to focus on the actual functionality and the usability of an interface.
